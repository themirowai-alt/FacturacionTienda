# FacturacionTienda

Módulo Java que calcula el importe final a cobrar a un cliente de una tienda:
aplica el descuento según el tipo de cliente, el recargo de envío y el IVA.

Práctica P2.1 de Entornos de Desarrollo (1.º DAW).

## Compilar y ejecutar

```bash
javac -d out src/FacturacionTienda.java
java -cp out FacturacionTienda
```
